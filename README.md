# DialMe

**Your Dialer. Your Style.**

DialMe is a modern, customizable, privacy-focused, offline-first Android SIM-based dialer built with Kotlin, Jetpack Compose, Material 3, Room, DataStore, and Android Telecom APIs.

## Core Principles
- **Real SIM-Based Calling Only**: Built on `TelecomManager`, `InCallService`, `CallScreeningService`, and `ROLE_DIALER`. No VoIP or internet calling.
- **100% Offline-First**: Declares **zero** `INTERNET` permissions. All T9 indexing, call notes, reminders, themes, and backups stay on-device.
- **Deep Customization**: Light, Dark, AMOLED, Dynamic Color, custom accents, gradients, Photo Picker background images, adjustable card transparency, keypad button shapes/layouts, custom fonts, and caller screen themes.
- **Bilingual**: Supports English and Bengali (`বাংলা`).
