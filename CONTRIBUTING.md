# Contributing to DialMe

DialMe is licensed under **GNU GPL v3 (`GPL-3.0-or-later`)**.

## Guidelines
- Keep the app 100% offline-first (do not add `INTERNET` permissions or VoIP libraries).
- Follow Clean Architecture + MVVM with Jetpack Compose and Material 3.
- Add or update unit/Robolectric tests for new domain logic or Room schema changes.
- Keep English (`values/strings.xml`) and Bengali (`values-bn/strings.xml`) translations in sync.
